# Berichte

Hier liegen zunächst **keine echten Geräteberichte**. Das Mac-Inventarskript
schreibt ausschließlich außerhalb des Repositorys. Rohprotokolle und Backups
dürfen auch in diesem privaten Repository nicht abgelegt werden.

Nach einem realen Pilotlauf kann eine kontrollierte Zusammenfassung aus
`templates/report.md` erstellt werden. Vor einem Commit vertrauliche Angaben
entfernen, Veröffentlichung bewusst prüfen und nur die konkrete freigegebene
Zusammenfassung hinzufügen. `.gitignore` sperrt neue Dateien hier zunächst.

Ein Cloud-Testbericht ist kein Gerätebefund. Projektvalidierung steht in
`docs/validation.md`.
